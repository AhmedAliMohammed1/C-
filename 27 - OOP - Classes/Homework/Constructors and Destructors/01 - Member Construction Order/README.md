# 1 - Member Construction Order

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 27 - OOP: Classes  
**Set:** Class Constructor and Destructor Homework  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Write a program to discover how declaration order and initializer-list order affect construction and destruction.

## Input

A containing class declares members A, B, C but lists them B, A, C in its initializer list.

## Output

Observed construction and destruction orders.

## Requirements and constraints

Use a program to investigate the question; the lecture also recommends checking a language reference.
