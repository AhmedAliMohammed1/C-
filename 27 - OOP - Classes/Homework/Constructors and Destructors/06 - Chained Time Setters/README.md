## Description

Change Time to support consecutive setter calls.

## Input

Time(3,1,2), followed by t.SetHours(5).SetMinutes(45).SetSeconds(13).

## Output

The first printed time is 3:1:2; after the setters it is 5:45:13.

## Requirements and constraints

Support chaining through the stated API; preserve the Time behavior.
