# 3 - Single Configuration Manager

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 27 - OOP: Classes  
**Set:** Class Const Static and Friend Homework 1  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Change the configuration manager so that only one instance can exist and its expensive configuration is loaded and cached once.

## Input

A manager storing a configuration map and an is-loaded flag; several functions currently create their own manager and call its lazy load.

## Output

A design and implementation sharing one manager.

## Requirements and constraints

Loading can take 30 minutes; retain lazy loading and prevent separate instances.
