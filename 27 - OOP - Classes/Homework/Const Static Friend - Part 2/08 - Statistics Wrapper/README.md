## Description

Wrap StudentGradesInfo with the same usable interface while recording global print and object-creation statistics.

## Input

Calls made by clients to the wrapper.

## Output

Original student-grade behavior plus the two statistics.

## Requirements and constraints

Clients use the wrapper. Delegate work to the original class and expose the requested counts through static functions.

Use the supplied StudentGradesInfo class in the preceding homework code-review README. Its required behavior is storing course grades, ignoring duplicate courses, retrieving a course by position, reporting grade totals, and tracking prints.
