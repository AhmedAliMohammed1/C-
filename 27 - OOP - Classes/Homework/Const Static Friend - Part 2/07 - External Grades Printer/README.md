**Problem:** 7  
**Source status:** Verified assignment

## Description

Extend printing without modifying the existing StudentGradesInfo implementation, using an iterator-like helper.

## Input

An existing student record and a printing limit.

## Output

Selected course/grade entries; e.g. print only three of four courses.

## Requirements and constraints

Provide has_next, get_next, and reset behavior through the new helper; preserve the old class.

## Assignment context

Use the supplied StudentGradesInfo class in the preceding homework code-review README. Its required behavior is storing course grades, ignoring duplicate courses, retrieving a course by position, reporting grade totals, and tracking prints.
