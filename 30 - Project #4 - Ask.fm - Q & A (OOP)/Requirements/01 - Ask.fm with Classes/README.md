## Description

Refactor the earlier Ask.fm project into an object-oriented design and compare the initial and final UML.

## Input

The earlier Ask.fm features and data.

## Output

An equivalent application organized into classes and its UML diagrams.

## Requirements and constraints

Model classes must not depend on views; views should not contain the business logic. Use appropriate private/public members, getters/setters, and const; minimize dependencies. Do not use friend. File separation is optional.
