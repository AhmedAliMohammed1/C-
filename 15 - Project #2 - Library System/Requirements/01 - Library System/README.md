## Description

Build an administrator console to manage books and users, search books, lend and return copies, and view records.

## Input

Books: ID, one-word name, quantity. Users: ID and one-word name. Menu choices, search prefixes, borrower names, and book names.

## Output

Matching books, book lists sorted by ID or name, borrowers of a chosen book, user records, and operation results.

## Requirements and constraints

IDs are supplied by the administrator. Lend only when a copy is available, record the loan, and decrease stock; return the copy and update the loan record and stock. No login/logout is required. Include an exit option.
