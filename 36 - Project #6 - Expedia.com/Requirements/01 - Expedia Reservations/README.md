## Description

Build a customer console for signup/login, profile, constructing itineraries, booking flights/hotels, viewing itineraries, and logout.

## Input

Account data; flight origin/destination/dates and adults/children/infants; hotel location/dates and adults/children; reservation selections and payment-card information.

## Output

Search results, itinerary details/totals, booking outcomes, and saved-in-memory customer itineraries.

## Requirements and constraints

Use the supplied simulated Air Canada, Turkish Airlines, Hilton, and Marriott APIs. An itinerary may contain multiple reservations. Support PayPal, Stripe, and Square with one active payment provider. Use local dummy APIs, no paid/live services or file persistence. Flight totals and hotel nights/rates contribute to the total. If part of booking fails, cancel prior successful reservations and handle payment rollback. Design the provider interactions for extension; admin functionality is deferred.
