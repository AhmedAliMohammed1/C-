# 3 - Even and Odd Position Sums

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 04 - Data Types and Variables  
**Set:** Variables Homework 1  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Read eight numbers and sum the even-positioned and odd-positioned values separately.

## Input

Eight integers in order.

## Output

Even-position sum, then odd-position sum.

## Requirements and constraints

Positions start at 1; position parity is different from value parity.

## Example

1 2 3 4 5 6 7 8: even positions 20, odd positions 16.
