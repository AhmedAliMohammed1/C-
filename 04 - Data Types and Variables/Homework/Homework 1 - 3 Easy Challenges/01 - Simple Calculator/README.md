## Description

Read two numbers and report their sum, difference, product, and quotient.

## Input

Two numbers.

## Output

The results of the four arithmetic operations.

## Requirements and constraints

Use a suitable numeric type. Consider zero, negative values, and large values when testing.

## Example

12 and 3: sum 15, difference 9, product 36, quotient 4.
