# 2 - Conditional Arithmetic

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 04 - Data Types and Variables  
**Set:** Variables Homework 3  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Produce one of two results based on the value of B.

## Input

Integers A and B; B is either -1 or 1.

## Output

2*A+1 when B=-1; A*A when B=1.

## Requirements and constraints

Express the result using one arithmetic formula at this stage, without selection statements.
