# 1 - Rotate Three Values

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 04 - Data Types and Variables  
**Set:** Variables Homework 3  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Rotate the values so A receives old B, B receives old C, and C receives old A.

## Input

Three integers A, B, C.

## Output

The values after rotation.

## Requirements and constraints

Optional challenge: perform the rotation with four statements.

## Example

150 20 301 -> 20 301 150.
