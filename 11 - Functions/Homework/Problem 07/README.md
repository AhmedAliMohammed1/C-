# 7 - Replace Substrings

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 11 - Functions  
**Set:** Functions Homework - 7 Challenges  
**Problem:** 7  
**Source status:** Verified assignment

## Description

Replace every nonoverlapping occurrence of a pattern with another string.

## Input

Lowercase input string, nonempty pattern, replacement string.

## Output

The replaced string.

## Requirements and constraints

The replacement may be empty. Implement the required starts_with(input, pattern, position) helper.

## Example

abab, pattern ab, replacement x -> xx.
