# 3 - Calculator Functions

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 11 - Functions  
**Set:** Functions Homework - 7 Challenges  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Build a repeating calculator menu with four arithmetic operations and exit.

## Input

Menu choices and two numeric operands per operation.

## Output

Operation results and the number of operations when exiting.

## Requirements and constraints

Read operands through a function using references; use separate functions for +, -, *, /. Handle division by zero.
