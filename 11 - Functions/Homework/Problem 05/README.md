# 5 - Set Powers with Defaults

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 11 - Functions  
**Set:** Functions Homework - 7 Challenges  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Fill an array so its element at index i equals m raised to i.

## Input

Array; optional length and m.

## Output

The populated array.

## Requirements and constraints

Default length=5 and m=2; test calls using the default arguments.

## Example

length=6, m=2 -> 1 2 4 8 16 32.
