# 1 - Integer Queue Structure

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 14 - Structures  
**Set:** Structures Practice  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Build an integer queue structure supporting add_end, add_front, remove_front, and print.

## Input

Operation calls and integer values.

## Output

The queue contents and the value returned by remove_front.

## Requirements and constraints

Place the queue state and operations together in a structure.

## Example

Add 10,20,30 at end, then 1 and 4 at front -> 4 1 10 20 30; remove_front returns 4.
