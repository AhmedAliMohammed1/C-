# 6 - Member Function Addresses

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 26 - Object Oriented Programming  
**Set:** Abstraction Homework  
**Problem:** 6  
**Source status:** Verified assignment

## Description

Write an experiment comparing a member function's address across ten objects.

## Input

A LuckyNum class with PrintAddress and ten objects.

## Output

Printed function addresses and a conclusion about whether they differ.

## Requirements and constraints

The slide supplies the C-style expression printf("Function address :%p\n", &LuckyNum::PrintAddress); examine it in the experiment.
