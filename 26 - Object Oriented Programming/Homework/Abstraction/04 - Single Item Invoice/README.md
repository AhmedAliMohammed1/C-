## Description

Implement an invoice for one kind of item.

## Input

Item name, item number, price, and quantity.

## Output

Getters/setters, total price, and a comma-separated string representation.

## Requirements and constraints

Separate declaration from definition, initially in one file; separate header/source files are also allowed.
