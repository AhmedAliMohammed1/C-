# 3 - Bank Customer Design Review

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 26 - Object Oriented Programming  
**Set:** Pyramid of Object Oriented Homework  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Review the supplied banking-customer fields for relevance and suitable types, and suggest at least two important missing fields.

## Input

BankCustomer contains string name, address, mobile, birth_of_date, favourite_movie, favourite_color, favourite_actor, favourite_car_model, favourite_food; int rectangle_width; and birth-date-related functions.

## Output

Design feedback and proposed missing members.

## Requirements and constraints

Judge relevance in the banking context, not simply whether a field can belong to a person.
