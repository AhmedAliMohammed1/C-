# 1 - Date and Time Design

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 26 - Object Oriented Programming  
**Set:** Pyramid of Object Oriented Homework  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Propose fields and operations for a reusable Date structure. Compare two ways to represent Time and defend each; explain how a team should make a practical decision.

## Input

Design context: a Date infrastructure component and Time measured in hours, minutes, and seconds.

## Output

Proposed members, formatting choices, and a comparison of the Time representations.

## Requirements and constraints

No fixed Date requirements are imposed. Consider different date string formats and reuse by many teams.
