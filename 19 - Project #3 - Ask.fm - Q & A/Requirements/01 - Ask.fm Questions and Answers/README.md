# 1 - Ask.fm Questions and Answers

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 19 - Project #3 - Ask.fm: Q & A  
**Set:** Project 3 - Ask.fm  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Build a file-persistent console for signup/login, asking and answering questions, viewing questions from/to the current user, listing users, and an answered-question feed.

## Input

Credentials, profile preferences, menu choices, user/question IDs, question text, and answer text.

## Output

User-specific questions, answers, user lists, the answered feed, and operation results.

## Requirements and constraints

Generate unique user/question IDs. Allow each recipient to accept or reject anonymous questions. Support a root question or one-level follow-up threads, deletion with associated thread cleanup, answering and updating an existing answer with a warning, and logout. Enforce user ownership/recipient permissions for edits and deletions. Persist user and question data in files.
