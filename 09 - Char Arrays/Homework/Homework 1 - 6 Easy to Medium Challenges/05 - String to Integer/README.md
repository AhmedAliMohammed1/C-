# 5 - String to Integer

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 09 - Char Arrays  
**Set:** Char Arrays Homework 1  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Convert a decimal digit string into its integer value.

## Input

A string of at most six digits.

## Output

Its integer value and three times that value.

## Requirements and constraints

Perform the conversion yourself; leading zeros are allowed.

## Example

0012 -> 12 and 36.
