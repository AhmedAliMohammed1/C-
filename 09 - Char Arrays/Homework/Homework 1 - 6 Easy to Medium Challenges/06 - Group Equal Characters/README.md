# 6 - Group Equal Characters

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 09 - Char Arrays  
**Set:** Char Arrays Homework 1  
**Problem:** 6  
**Source status:** Verified assignment

## Description

Split the string into maximal runs of equal consecutive characters.

## Input

A string.

## Output

The runs as separate groups.

## Requirements and constraints

A repeated character in a later run starts a new group.

## Example

aaabbcaa -> aaa bb c aa.
