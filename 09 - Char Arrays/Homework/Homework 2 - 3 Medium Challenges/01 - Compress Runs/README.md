# 1 - Compress Runs

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 09 - Char Arrays  
**Set:** Char Arrays Homework 2  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Represent each consecutive run by its character and length.

## Input

A string.

## Output

Character/count groups separated by underscores.

## Requirements and constraints

Keep the order of the runs.

## Example

CCCCDDDXXXXXXXXE -> C4_D3_X8_E1.
