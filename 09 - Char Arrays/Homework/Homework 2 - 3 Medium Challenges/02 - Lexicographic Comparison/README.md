# 2 - Lexicographic Comparison

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 09 - Char Arrays  
**Set:** Char Arrays Homework 2  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Compare two strings in dictionary order by examining their characters.

## Input

Two strings.

## Output

YES if the first string is lexicographically less than or equal to the second; otherwise NO.

## Requirements and constraints

Do not use < between whole strings; use loops to compare their characters.

## Example

abc abd -> YES.
