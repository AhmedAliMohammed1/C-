# 1 - Employee System

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 09 - Char Arrays  
**Set:** Char Arrays Homework 3 - Application  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Build a repeating menu to add employees, list them, delete employees in an inclusive age range, and update a salary by name.

## Input

Menu choices; employee name, age, salary, and gender; age-range bounds or an employee name and new salary.

## Output

Employee listings and the results of each requested operation.

## Requirements and constraints

Names are one word. Continue accepting operations through the menu.
