# 2 - Lowercase Frequencies

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 09 - Char Arrays  
**Set:** Char Arrays Practice  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Count and print the lowercase English letters in the input.

## Input

A string.

## Output

Each occurring lowercase letter and its count, in alphabetical order.

## Requirements and constraints

Ignore uppercase letters rather than converting them.

## Example

aAb -> a:1, b:1.
