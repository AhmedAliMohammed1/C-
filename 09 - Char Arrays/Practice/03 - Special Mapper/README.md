# 3 - Special Mapper

**Section:** 09 - Char Arrays  
**Set:** Char Arrays Practice  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Convert lowercase letters and digits using the supplied mapping, leaving uppercase letters unchanged.

## Input

A string of letters and digits.

## Output

The converted string.

## Requirements and constraints

Use the mapping table included below.

## Assignment context

Map corresponding positions in these rows:

~~~text
abcdefghijklmnopqrstuvwxyz
YZIMNESTODUAPWXHQFBRJKCGVL

0123456789
!@#$%^&*()
~~~

Uppercase letters stay unchanged. Source example: acMNmn39 -> YIMNPW$).
