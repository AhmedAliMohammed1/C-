**Section:** 09 - Char Arrays  
**Set:** Char Arrays Practice

## Description

Alternate characters from two strings, then print any remaining characters of the longer string.

## Input

Two strings.

## Output

The interleaved result.

## Requirements and constraints

Print directly without building a new string or modifying the inputs.

## Example

abc XY -> aXbYc.
