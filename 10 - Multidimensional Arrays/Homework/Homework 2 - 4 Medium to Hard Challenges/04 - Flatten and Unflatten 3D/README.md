**Course:** Mastering 4 Critical SKILLS Using C++ 17

**Set:** Multidimensional Arrays Homework 2  
**Problem:** 4  
**Source status:** Verified assignment

## Description

Convert between depth/row/column coordinates and a flat index.

## Input

Depth, rows, columns; operation 1 and three coordinates, or operation 2 and a flat index.

## Output

The corresponding index or three coordinates.

## Requirements and constraints

Use 0-based order with columns varying fastest, then rows, then depth.
