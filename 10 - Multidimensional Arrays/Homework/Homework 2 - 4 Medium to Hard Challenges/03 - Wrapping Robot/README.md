# 3 - Wrapping Robot

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 10 - Multidimensional Arrays  
**Set:** Multidimensional Arrays Homework 2  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Simulate movement on a grid that wraps at its boundaries.

## Input

N, M, K; K pairs of direction and step count.

## Output

The robot position after every command.

## Requirements and constraints

Start at (0,0). Directions: 1 up, 2 right, 3 down, 4 left. Step counts may be very large.
