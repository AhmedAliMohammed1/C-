# 1 - Primes in Submatrices

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 10 - Multidimensional Arrays  
**Set:** Multidimensional Arrays Homework 2  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Count prime-valued cells in each requested rectangular region.

## Input

Matrix dimensions and values; queries giving a starting row, starting column, height, and width.

## Output

One count per query.

## Requirements and constraints

Starting coordinates are 0-based. Count repeated prime values separately. Aim for at most two nested loops per query.
