# 1 - Tic Tac Toe

**Course:** Mastering 4 Critical SKILLS Using C++ 17

**Set:** Multidimensional Arrays Homework 3 - Application  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Run an N by N game with alternating X and O turns, display the board, and detect a win or draw.

## Input

N and a row/column move on each turn.

## Output

The board after each valid move and the game result.

## Requirements and constraints

N<=9; move coordinates are 1-based. Reject occupied or out-of-range cells and retry the turn for the same player. Wins fill a row, column, or either full diagonal.
