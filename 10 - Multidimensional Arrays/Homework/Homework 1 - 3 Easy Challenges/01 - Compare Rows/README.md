# 1 - Compare Rows

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 10 - Multidimensional Arrays  
**Set:** Multidimensional Arrays Homework 1  
**Problem:** 1  
**Source status:** Verified assignment

## Description

For each query, check whether every element of one row is strictly smaller than the corresponding element of another.

## Input

Dimensions, matrix, Q, and Q pairs of row numbers.

## Output

YES or NO per query.

## Requirements and constraints

Query row numbers are 1-based; every corresponding column must pass.
