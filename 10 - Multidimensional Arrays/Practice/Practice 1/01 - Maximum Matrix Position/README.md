# 1 - Maximum Matrix Position

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 10 - Multidimensional Arrays  
**Set:** Multidimensional Arrays Practice 1  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Find the maximum element and its position.

## Input

Row and column counts followed by the matrix.

## Output

The maximum value and row/column indices.

## Requirements and constraints

Use 0-based positions. If the maximum repeats, use its last occurrence in row-major traversal.
