# 1 - Greedy Robot Path

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 10 - Multidimensional Arrays  
**Set:** Multidimensional Arrays Practice 2  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Start at the top-left cell. At each step choose the largest immediately available value among right, down, and down-right, and add every visited value.

## Input

Dimensions and a matrix with distinct values.

## Output

The total along the resulting path.

## Requirements and constraints

Only the stated moves are allowed; stop when no move remains. The largest-neighbor rule is part of the assignment.
