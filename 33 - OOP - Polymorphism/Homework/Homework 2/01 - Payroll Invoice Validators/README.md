## Description

Extend payroll with growing invoice-validation rules and configurable groups of rules.

## Input

An invoice and a chosen group containing a subset of the available validation rules.

## Output

Whether the invoice passes the whole selected group.

## Requirements and constraints

Every selected rule must pass. Model rules/groups so more can be added later.
