# 5 - Cloneable Printable Comparable Payroll

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 33 - OOP: Polymorphism  
**Set:** Polymorphism Homework 2  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Implement payables that can be cloned, printed, and compared, plus a payroll collection that can print and sort them.

## Input

Employees with name/salary and invoices with total costs.

## Output

Employees first, then invoices; each group sorted, and the total payable amount.

## Requirements and constraints

Sort employees by salary then name and invoices by total cost. Support the requested capabilities through interfaces.
