# 2 - Itinerary Reservations

**Course:** Mastering 4 Critical SKILLS Using C++ 17

**Set:** Polymorphism Homework 2  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Design reservation classes and itineraries whose total cost combines their reservations.

## Input

An itinerary containing zero or more flights and hotels.

## Output

Its reservation details and total cost.

## Requirements and constraints

Only one-way flights without transit and hotel reservations are needed; exclude cars/cruises. Hotel cost depends on nights and price per night. This is the reservation model, not the whole website.
