# 3 - Company Payroll

**Course:** Mastering 4 Critical SKILLS Using C++ 17

**Set:** Polymorphism Homework 1  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Design a payroll that calculates and pays eligible employee and invoice costs, then evaluate a proposed Labourer type.

## Input

Volunteers; hourly employees; salaried employees; commission salaried employees; invoices containing items with differing fields.

## Output

A class model and payment behavior for payables.

## Requirements and constraints

Volunteers are not paid. Hourly pay depends on hours; commission employees receive salary plus sales-based commission. Invoice items may have type-specific details. Discuss whether to add an empty Labourer subclass when it adds no fields or behavior.
