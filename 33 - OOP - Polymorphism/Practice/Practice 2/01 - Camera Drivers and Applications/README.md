**Set:** Polymorphism Practice 2

## Description

Model camera applications that work with different camera drivers through a common device interface.

## Input

Camera drivers for Ubuntu/open-source, a faster variant, and Windows; applications such as Cheese and Kamoso.

## Output

A simulation that starts a device, retrieves frames, and stops it.

## Requirements and constraints

Use the device/camera interface so the applications can work with different drivers; include run/shutdown behavior.

## Assignment context

This is the worked scenario in a named practice lecture. Recreate its device/driver/application model as practice; the instructor demonstrates the implementation rather than presenting a separately numbered homework.
