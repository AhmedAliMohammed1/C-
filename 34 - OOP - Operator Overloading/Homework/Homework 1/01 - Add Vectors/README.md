**Set:** Operator Overloading Homework 1  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Add integer vectors element by element over their shared length, retaining the unmatched tail of the longer vector.

## Input

Two vectors.

## Output

The resulting vector.

## Requirements and constraints

Overload + for the vector operation.

## Example

[1,2,3,4] + [10,20] -> [11,22,3,4].
