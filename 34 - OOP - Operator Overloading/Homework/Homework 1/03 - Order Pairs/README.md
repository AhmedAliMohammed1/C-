**Set:** Operator Overloading Homework 1  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Add a member operator< to MyPair so a vector of pairs can be sorted as in the example.

## Input

Pairs containing two values.

## Output

The sorted pairs.

## Requirements and constraints

Retain the existing print operation; only the comparison operator is requested.

## Example

(10,20), (10,7), (1,200) -> (1,200), (10,7), (10,20).
