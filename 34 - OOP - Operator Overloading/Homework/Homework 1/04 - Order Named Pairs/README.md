**Set:** Operator Overloading Homework 1  
**Problem:** 4

## Description

Derive NamedPair from MyPair, adding a string name, comparison, and printing that includes the name.

## Input

Named pairs.

## Output

Named pairs sorted according to the example.

## Requirements and constraints

Reuse the parent comparison rather than duplicating its logic; override print.

## Example

(A,10,20), (B,10,7), (B,1,200) -> (A,10,20), (B,1,200), (B,10,7).
