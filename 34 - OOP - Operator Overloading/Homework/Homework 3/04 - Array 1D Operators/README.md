**Set:** Operator Overloading Homework 3

**Source status:** Verified assignment

## Description

Implement a one-dimensional dynamic array with the requested operators.

## Input

Array length, element values, stream input, and operator calls.

## Output

Stored/read values, printed array, increments, comparisons, and assignment results.

## Requirements and constraints

Store a pointer and size. Support [] reads/writes, >> and <<, prefix/postfix ++ that increase every cell by 1, == and !=, and array assignment.
