## Description

Implement a map with parallel name/value vectors and two forms of subscript access.

## Input

String-to-integer assignments, string lookups, integer reverse lookups, and iteration calls.

## Output

The latest value for a name, all names with a requested value, and all stored entries.

## Requirements and constraints

Use vector<string> and vector<int>. Support has_next/get_next iteration.

## Example

Mostafa=20 then Mostafa=40 -> 40; Sayed=20 and Ali=20 -> both names when querying 20.
