# 5 - Last Three Digits Classification

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Practice  
**Problem:** 5  
**Source status:** Verified assignment

## Description

For N below 10000, report a small number. Otherwise sum its last three digits: an odd sum means great; an even sum with any odd digit means good; otherwise bad.

## Input

An integer N.

## Output

A small, great, good, or bad number message.

## Requirements and constraints

Create tests for all cases. The assignment slide uses 10000; a later solution slide uses 1000, a source discrepancy recorded in COVERAGE.md.

## Example

10000 -> bad number.
