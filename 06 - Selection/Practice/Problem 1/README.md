# 1 - Simple Calculator

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Practice  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Read an arithmetic expression and calculate its value.

## Input

A number, an operation character, and another number.

## Output

The operation result.

## Requirements and constraints

Support +, -, *, and /. Use a numeric type that supports fractional division.

## Example

7 + 55 -> 62.
