# 4 - Special Digit Processing

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Practice  
**Problem:** 4  
**Source status:** Verified assignment

## Description

If N is even, print its last digit. If N is odd and below 1000, print its last two digits; if odd and from 1000 to below 1000000, print its last four digits; otherwise print -N.

## Input

An integer N.

## Output

The value selected by these rules.

## Requirements and constraints

Apply the cases in the stated order.

## Example

234 -> 4; 157 -> 57.
