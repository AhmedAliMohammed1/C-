# 1 - Arithmetic by Parity

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Homework 1  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Choose an operation from the parity of A and B: both odd multiply; both even divide; odd A and even B add; even A and odd B subtract.

## Input

Two integers A, B.

## Output

The selected arithmetic result.

## Requirements and constraints

The divisor must allow the division to be defined.

## Example

3 5 -> 15.
