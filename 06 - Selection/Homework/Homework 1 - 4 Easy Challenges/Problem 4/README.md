# 4 - Count Relative to X

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Homework 1  
**Problem:** 4  
**Source status:** Verified assignment

## Description

Count how many of five numbers are at most X and how many are greater.

## Input

X followed by five numbers.

## Output

The two counts.

## Requirements and constraints

Every number belongs to exactly one count; reflect on the sum of the counts.

## Example

X=5; 1 5 9 2 8 -> 3 and 2.
