# 3 - Maximum below 100

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Homework 1  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Find the largest of the three inputs that is strictly below 100.

## Input

Three numbers.

## Output

The largest eligible value, or -1 if no value qualifies.

## Requirements and constraints

100 itself is not eligible.

## Example

99 100 150 -> 99.
