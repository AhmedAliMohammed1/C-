# 1 - Count Containing Intervals

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Homework 3  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Count the intervals containing a given value.

## Input

X and three intervals, each with start and end.

## Output

The number of intervals containing X.

## Requirements and constraints

Endpoints are inclusive; each interval has start at most end.

## Example

X=3; [1,3], [4,8], [0,5] -> 2.
