# 2 - Interval Intersection

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 06 - Selection  
**Set:** Selection Homework 3  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Find the common part of two intervals.

## Input

Two start/end pairs.

## Output

The intersection endpoints, or -1 when there is no intersection.

## Requirements and constraints

Treat endpoints as inclusive.

## Example

[1,6] and [3,8] -> [3,6].
