# 1 - Hospital System

**Course:** Mastering 4 Critical SKILLS Using C++ 17

**Set:** Project 1 - Hospital System  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Build a menu to add a patient, list waiting queues, send the next patient to a doctor, and exit.

## Input

Specialization number, patient name, status, and menu choices.

## Output

Queue listings, admission results, and the next patient for a selected specialization.

## Requirements and constraints

There are 20 specializations numbered 1..20, each holding at most 5 waiting patients. Status 0 is regular and 1 urgent. Regular patients join the back; new urgent patients join the front. Reject a full queue; removing the next patient takes the front. Do not list empty queues.
