# C++ Learning Journey

This repository is an **educational workspace** for practicing C++ and documenting my progress while following the Udemy course [Mastering 4 critical SKILLS using C++ 17](https://www.udemy.com/course/cpp-4skills/).

The repository is organized to mirror the course syllabus. Each folder corresponds to one course section and will gradually contain my own:

- C++ practice code
- Homework solutions
- Exercises and experiments
- Project implementations
- Notes and learning summaries

## Learning Goals

The course focuses on developing four complementary skills:

1. **Programming skills** — learning modern C++ syntax and language features.
2. **Problem-solving skills** — solving progressively more challenging programming problems.
3. **Project-building skills** — applying C++ concepts in larger practical projects.
4. **Design skills** — improving code organization, object-oriented programming, and software design.

The curriculum covers C++ fundamentals, functions, recursion, arrays, pointers, templates, STL, files, exception handling, debugging, object-oriented programming, and modern C++ features such as move semantics, lambda expressions, smart pointers, and wrapper types.
