# 1 - Full Name Prefix Search

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Practice 4  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Find all stored names that start with the queried sequence of whole words.

## Input

N names, each given as K followed by K words; Q queries in the same format.

## Output

All matching full names for each query.

## Requirements and constraints

Match complete words from the beginning and retain the names order.

## Example

Mostafa Saad matches the prefix Mostafa.
