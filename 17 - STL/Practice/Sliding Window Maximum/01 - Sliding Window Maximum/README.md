# 1 - Sliding Window Maximum

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Practice 5  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Find the largest value in each consecutive window of K elements.

## Input

An integer vector and K.

## Output

A vector of window maximums in window order.

## Requirements and constraints

Return one result for every full window.

## Example

[1,3,-1,-3,5,3,6,7], K=3 -> [3,3,5,5,6,7].
