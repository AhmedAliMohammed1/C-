# 1 - Maximum Equal Stack Sum

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Practice 2 - Stack  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Remove zero or more top items from three stacks so their remaining sums are equal and as large as possible.

## Input

Three vectors representing stacks.

## Output

The largest common remaining sum.

## Requirements and constraints

The vector end is the stack top. Example values are nonnegative; empty stacks permit sum zero.

## Example

[1,2,3,4], [2,2,2,4,0], [0,3,3,5] -> 6.
