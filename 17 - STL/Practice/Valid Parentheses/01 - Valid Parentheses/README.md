## Description

Check whether all brackets are matched and correctly nested.

## Input

A string containing (), [], and {} brackets.

## Output

A boolean validity result.

## Requirements and constraints

Matching bracket types and nesting both matter.

## Example

([]{}) -> true; ([)] -> false.
