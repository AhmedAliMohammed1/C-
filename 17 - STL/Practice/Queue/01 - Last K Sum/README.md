# 1 - Last K Sum

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Practice 1 - Queue  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Process an integer stream, returning the sum of its most recent K values after each addition.

## Input

K and successive calls to next(num).

## Output

The sum after each call.

## Requirements and constraints

Store at most K stream values; before K values arrive, sum all received values.

## Example

K=4; 1 2 3 4 5 -> 1 3 6 10 14.
