# 7 - Parentheses Score

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Homework 2 - Problems 7 to 9  
**Problem:** 7  
**Source status:** Verified assignment

## Description

Evaluate a balanced parentheses string under the supplied scoring rules.

## Input

A balanced parentheses string.

## Output

Its score.

## Requirements and constraints

() has score 1; concatenated groups add their scores; wrapping a group in parentheses doubles its score.

## Example

(()(())) -> 6.
