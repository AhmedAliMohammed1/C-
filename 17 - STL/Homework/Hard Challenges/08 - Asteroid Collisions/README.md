# 8 - Asteroid Collisions

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Homework 2 - Problems 7 to 9  
**Problem:** 8  
**Source status:** Verified assignment

## Description

Find which moving asteroids survive all collisions.

## Input

A sequence of signed sizes; positive moves right, negative moves left.

## Output

The surviving signed sizes in their original order.

## Requirements and constraints

All move at the same speed. The smaller absolute size is destroyed in a collision; equal sizes destroy both.

## Example

5 10 -5 -> 5 10.
