# 9 - Next Greater Element

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Homework 2 - Problems 7 to 9  
**Problem:** 9  
**Source status:** Verified assignment

## Description

For each value, find the first strictly larger value to its right.

## Input

An integer sequence.

## Output

One next-greater value per position, or -1 when none exists.

## Requirements and constraints

Aim for one traversal; the assignment asks you to consider using a stack.

## Example

2 1 3 -> 3 3 -1.
