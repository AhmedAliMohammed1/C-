# 6 - Remove Adjacent Duplicates

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 17 - STL  
**Set:** STL Homework 1 - Problems 1 to 6  
**Problem:** 6  
**Source status:** Verified assignment

## Description

Repeatedly remove adjacent equal-character pairs until no such pair remains.

## Input

A string.

## Output

The final string.

## Requirements and constraints

Removal can expose a new adjacent pair that must also be removed.

## Example

abbaca -> ca.
