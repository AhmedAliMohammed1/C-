**Course:** Mastering 4 Critical SKILLS Using C++ 17

## Description

Explain why inherited fields cannot be initialized directly in a derived initializer list, why friendship is not inherited/transitive, how base/derived sets relate, whether private fields are inherited, and the tradeoffs of protected data versus getters/setters.

## Input

The five questions; use Vehicle and Honda for the base/derived example.

## Output

Reasoned answers to all five.

## Requirements and constraints

Consider state corruption and coupling when discussing protected members.
