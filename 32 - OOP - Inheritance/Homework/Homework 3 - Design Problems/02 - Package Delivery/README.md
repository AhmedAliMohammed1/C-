# 2 - Package Delivery

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 32 - OOP: Inheritance  
**Set:** Inheritance Homework 3  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Design classes for customers, shipments, different packages, addresses, and payment cards.

## Input

Sender/receiver addresses; weight and price per kg; package type; customer shipments and cards.

## Output

Package costs and shipment totals through the class model.

## Requirements and constraints

Standard cost is weight*price_per_kg. Two-day adds a fixed fee. Heavy adds (weight-100)*extra_rate only above 100 kg. A shipment contains mixed package types and uses a debit/credit card. An address has city, street name, and number. No main is required.
