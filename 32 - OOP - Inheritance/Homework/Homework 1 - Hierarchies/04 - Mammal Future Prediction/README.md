## Description

Explain what the supplied mammal hierarchy implies, then identify a mammal that would challenge it.

## Input

Mammal declares bool givesMilk(), string makeSound(), and bool givesLiveBirth(). Cat, Monkey, and Whale derive from it and provide makeSound().

## Output

Design reasoning and a proposed counterexample animal.

## Requirements and constraints

Assume the design works for the three current animals; think first, then research the counterexample.
