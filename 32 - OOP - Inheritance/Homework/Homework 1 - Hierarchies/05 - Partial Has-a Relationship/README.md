# 5 - Partial Has-a Relationship

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 32 - OOP: Inheritance  
**Set:** Inheritance Homework 1  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Discuss the problem of composing several classes when a new class needs only part of each class's behavior.

## Input

Four existing classes each have 20 functions. In the example, Robot drives, cleans, and does funny actions; real animals make sounds and use the toilet; a RobotDog needs robot functions and sound but no toilet behavior.

## Output

An explanation of the composition/design difficulty.

## Requirements and constraints

Use the stated partial-behavior scenario.
