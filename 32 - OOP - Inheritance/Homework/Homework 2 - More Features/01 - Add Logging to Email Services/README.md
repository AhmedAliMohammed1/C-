## Description

Extend the email design to make logging available with every existing feature combination.

## Input

Four existing services: basic; basic+retries; basic+thread-safe; basic+retries+thread-safe.

## Output

A UML design supporting the old cases and versions with logging.

## Requirements and constraints

Do not modify existing classes; reuse/extend them. Retain versions without logging. Each class should have one reason to change.
