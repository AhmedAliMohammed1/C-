## Description

Provide a string class with the existing string features plus a decorate member that wraps its current text.

## Input

A string and a call to decorate().

## Output

The decorated text and the normal string operations.

## Requirements and constraints

Keep the available string constructors/operators/features. Decoration produces <<[[text]]>>.
