## Description

Compare periodic client polling with server-sent updates for a game with millions of online players.

## Input

A Medal of Honor notification service and registered client applications.

## Output

A comparison of both options and implementation considerations.

## Requirements and constraints

One option polls every two minutes; the other has clients register and the server sends updates to them.
