# 1 - Online Book Reader

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 31 - Project #5: Online Book Reader  
**Set:** Project 5 - Online Book Reader  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Build a console with administrator book creation and customer signup/login, profile, book listing, reading, and reading history.

## Input

Account details, book data, menu choices, book/session choices, and reading actions.

## Output

Book pages, current/total page numbers, profile, and dated history entries that can be resumed.

## Requirements and constraints

Use a hardcoded admin login. Read one book at a time with previous/next/stop operations. Store the last page and timestamp for each session, including multiple sessions of one book. Preserve history across logout/login within the run. Use memory only, no files or concurrency; strings contain no spaces and users may be assumed well behaved. Dummy pages are allowed. Draw and compare initial/final UML.
