**Problem:** 1  
**Source status:** Verified assignment

## Description

Generate the sequence starting at a0=0. For step i, subtract i from the preceding value if the result is positive and unseen; otherwise add i.

## Input

An index n.

## Output

an.

## Requirements and constraints

n is between 1 and 200. Do not use nested loops.

## Example

n=6 -> 13; n=9 -> 21; n=17 -> 25.
