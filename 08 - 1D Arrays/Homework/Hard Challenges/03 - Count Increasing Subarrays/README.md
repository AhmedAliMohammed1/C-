# 3 - Count Increasing Subarrays

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 3 - 5 Hard Challenges  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Count all contiguous subarrays that are nondecreasing.

## Input

N followed by N integers.

## Output

The number of qualifying subarrays.

## Requirements and constraints

Include single-element subarrays. Progress from three loops to two, then aim for one.

## Example

Four strictly increasing values -> 10; four strictly decreasing values -> 4.
