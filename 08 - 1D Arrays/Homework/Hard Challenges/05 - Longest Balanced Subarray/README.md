# 5 - Longest Balanced Subarray

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 3 - 5 Hard Challenges  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Find the longest contiguous region containing equally many zeros and ones.

## Input

N followed by N binary values.

## Output

The length of the longest balanced subarray.

## Requirements and constraints

Try successively reducing three nested loops to two and then avoiding nested loops. Optional follow-up: longest zero-sum subarray.

## Example

0 1 0 1 -> 4.
