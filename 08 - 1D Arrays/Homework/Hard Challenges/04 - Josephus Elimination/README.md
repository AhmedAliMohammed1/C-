# 4 - Josephus Elimination

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 3 - 5 Hard Challenges  
**Problem:** 4  
**Source status:** Verified assignment

## Description

Arrange people numbered 1..N in a circle and repeatedly remove every Kth person until all are removed.

## Input

N and K.

## Output

The complete elimination order, including the final person.

## Requirements and constraints

N<200; K<=1000000. Start counting at person 1. After removing a person, continue from the next surviving person. First solve for small K, then develop an efficient version for large K.

## Example

N=4, K=2 -> 2 4 3 1.
