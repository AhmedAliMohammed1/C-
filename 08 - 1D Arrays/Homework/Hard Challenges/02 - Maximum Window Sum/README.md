# 2 - Maximum Window Sum

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 3 - 5 Hard Challenges  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Find a contiguous window of exactly K elements with the largest sum.

## Input

K, N, and N numbers.

## Output

The window's start, end, and sum.

## Requirements and constraints

K<=N. Aim to remove nested loops; an initial nested-loop version is allowed.
