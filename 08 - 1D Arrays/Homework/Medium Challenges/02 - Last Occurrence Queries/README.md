# 2 - Last Occurrence Queries

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 2 - 6 Medium Challenges  
**Problem:** 2  
**Source status:** Verified assignment

## Description

For each query value, report its last position in the array.

## Input

N and N values, then Q and Q query values.

## Output

One last index per query, or -1 when absent.

## Requirements and constraints

Values range from 0 through 500; indices are 0-based. Avoid nested scanning of the array for each query.
