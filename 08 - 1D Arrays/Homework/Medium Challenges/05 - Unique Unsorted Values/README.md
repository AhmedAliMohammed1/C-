# 5 - Unique Unsorted Values

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 2 - 6 Medium Challenges  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Remove repeated values while preserving their first-appearance order.

## Input

N followed by N integers.

## Output

The unique sequence.

## Requirements and constraints

N<=900; values 0..500. Do not use nested loops.

## Example

3 1 3 2 1 -> 3 1 2.
