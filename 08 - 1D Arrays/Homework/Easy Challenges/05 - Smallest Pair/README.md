# 5 - Smallest Pair

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 1 - 5 Easy to Medium Challenges  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Find the minimum of A[i]+A[j]+j-i over distinct positions with i<j.

## Input

N followed by N numbers.

## Output

The smallest expression value.

## Requirements and constraints

N<=200; the slide uses 1<=i<j<=N. Be able to justify your result.

## Example

N=4, array 20 1 9 4 -> 7.
