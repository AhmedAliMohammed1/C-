# 3 - Unique Sorted Values

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 1 - 5 Easy to Medium Challenges  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Print the distinct values of the sorted input, preserving its order.

## Input

N followed by N sorted integers.

## Output

Each different value once.

## Requirements and constraints

N<1000; values 0..500. No nested loops; use only one array, or no array.

## Example

1 1 2 5 5 -> 1 2 5.
