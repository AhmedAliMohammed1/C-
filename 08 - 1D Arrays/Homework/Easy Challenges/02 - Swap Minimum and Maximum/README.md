# 2 - Swap Minimum and Maximum

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 08 - 1D Arrays  
**Set:** 1D Arrays Homework 1 - 5 Easy to Medium Challenges  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Replace every occurrence of the minimum with the maximum and every maximum with the minimum.

## Input

N followed by N integers.

## Output

The modified array.

## Requirements and constraints

Apply the change to all occurrences.

## Example

1 3 1 5 -> 5 3 5 1.
