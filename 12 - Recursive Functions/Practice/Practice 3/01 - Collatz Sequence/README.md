# 1 - Collatz Sequence

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 12 - Recursive Functions  
**Set:** Recursive Functions Practice 3  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Print the sequence starting at N, halving even values and replacing an odd value by 3*N+1, until reaching 1.

## Input

A positive integer N.

## Output

All sequence values including N and 1.

## Requirements and constraints

Use recursion; the transformation rules are part of the assignment.

## Example

6 -> 6 3 10 5 16 8 4 2 1.
