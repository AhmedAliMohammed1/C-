# 7 - Prefix Accumulation

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 12 - Recursive Functions  
**Set:** Recursive Functions Homework 1 - Problems 1 to 8  
**Problem:** 7  
**Source status:** Verified assignment

## Description

Replace each element by the sum of the original elements through that position.

## Input

Array and length.

## Output

The modified prefix-sum array.

## Requirements and constraints

Use recursion and update the array in place.

## Example

1 2 3 -> 1 3 6.
