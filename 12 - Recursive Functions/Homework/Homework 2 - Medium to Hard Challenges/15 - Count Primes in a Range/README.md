# 15 - Count Primes in a Range

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 12 - Recursive Functions  
**Set:** Recursive Functions Homework 2 - Problems 9 to 17  
**Problem:** 15  
**Source status:** Verified assignment

## Description

Count primes between start and end inclusive.

## Input

Start and end integers.

## Output

The number of primes.

## Requirements and constraints

Do not use loops. Discuss the behavior for a range such as 10 through 5000000.

## Example

10 20 -> 4.
