# 16 - Recursive Robot Path

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 12 - Recursive Functions  
**Set:** Recursive Functions Homework 2 - Problems 9 to 17  
**Problem:** 16  
**Source status:** Verified assignment

## Description

Implement the earlier greedy robot path using recursion.

## Input

Dimensions and a matrix of distinct values.

## Output

The sum along the greedy path from the top-left cell.

## Requirements and constraints

Use recursion through path_sum(grid, row, column, maximum_row, maximum_column), initially called at (0,0). Allowed moves are right, down, and down-right, choosing the largest immediate neighbor.
