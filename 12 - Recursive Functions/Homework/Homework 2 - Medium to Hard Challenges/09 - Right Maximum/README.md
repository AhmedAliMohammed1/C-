# 9 - Right Maximum

**Course:** Mastering 4 Critical SKILLS Using C++ 17

**Set:** Recursive Functions Homework 2 - Problems 9 to 17  
**Problem:** 9  
**Source status:** Verified assignment

## Description

Replace each element by the largest original value at or after it.

## Input

Array, length, and start position.

## Output

The modified array.

## Requirements and constraints

Use recursion with the required start_position argument.

## Example

3 1 4 2 -> 4 4 4 2.
