**Set:** Division and Modulus Homework 2

**Source status:** Verified assignment

## Description

Add the last three decimal digits of an integer.

## Input

An integer.

## Output

The sum of its last three digits.

## Requirements and constraints

For fewer than three digits, the missing leading digits contribute zero.

## Example

1234 -> 9; 15 -> 6.
