# 3 - Simplify Expressions

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 05 - Operators  
**Set:** Logical Operators Homework  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Simplify each supplied expression by hand until it is true or false.

## Input

Eight expressions using T=true and F=false.

## Output

Step-by-step simplifications and the final truth value of each.

## Requirements and constraints

Optional: write code to check the result after doing the manual work.

## Assignment context

Use T for true and F for false. Simplify these expressions:

~~~text
T && T && F && T
T && T && F && T || T && T
T && T && T && T || T && (T || F)
T && T && T || T && (F || (T && (T && T)))
T && T || T && F && T || T && T && F || (T && (T || F))
T && T || T && F && T || (T && T && F || (T && (T || F)))
(T && T || T && F && T || T) && T && F || (T && (T || F))
T && T || T && (F && T || T && T) && F || (T && (T || F))
~~~
