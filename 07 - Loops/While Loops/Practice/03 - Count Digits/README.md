# 3 - Count Digits

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** While Loops Practice  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Count the decimal digits of the input and report the count with the original value.

## Input

An integer.

## Output

Its digit count.

## Requirements and constraints

Include zero and negative numbers in testing. Consider the minimum integer value and preserve the original input.

## Example

0 has 1 digit; -123 has 3.
