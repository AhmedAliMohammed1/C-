# 3 - Multiplication Table

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** While Loops Homework 3  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Print all products for the requested two ranges.

## Input

N and M.

## Output

Entries for i from 1 through N and j from 1 through M, showing operands and product.

## Requirements and constraints

Use nested while loops.

## Example

2 x 3 = 6 is one entry when N>=2 and M>=3.
