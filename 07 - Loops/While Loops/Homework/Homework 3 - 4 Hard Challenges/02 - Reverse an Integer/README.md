# 2 - Reverse an Integer

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** While Loops Homework 3  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Reverse the decimal digits, then print the reversed number and three times that number.

## Input

An integer.

## Output

The reversed number and its triple.

## Requirements and constraints

Treat the reversed result as an integer, so leading zeros disappear.

## Example

120 -> 21 and 63.
