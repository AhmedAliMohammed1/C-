# 4 - Special Sum

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** While Loops Homework 3  
**Problem:** 4  
**Source status:** Verified assignment

## Description

For each test case compute a1 + a2 squared + a3 cubed, continuing with exponent i for ai.

## Input

T; each case has N followed by N numbers.

## Output

One special sum per case.

## Requirements and constraints

Use while loops, including repeated multiplication for powers.

## Example

Values 2 3 4 -> 2 + 9 + 64 = 75.
