# 1 - NO Strings

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** While Loops Homework 3  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Print only two-character strings consisting of one N and one O, in either order and any letter case.

## Input

N followed by N strings.

## Output

The qualifying strings.

## Requirements and constraints

Reject longer strings and NN or OO; use while loops.

## Example

NO, on, nO qualify; NN and NOO do not.
