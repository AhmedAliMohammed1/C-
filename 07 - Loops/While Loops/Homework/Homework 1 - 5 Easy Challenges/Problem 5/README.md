# 5 - Position Averages

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** While Loops Homework 1  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Calculate separate averages for the values at odd and even positions.

## Input

N followed by N numbers.

## Output

Odd-position average, then even-position average.

## Requirements and constraints

Positions are 1-based. Preserve fractional averages; use while loops.

## Example

1 2 3 4 -> averages 2 and 3.
