**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops

## Description

Print every integer from X through Y.

## Input

Two integers X, Y.

## Output

One value per line from X to Y inclusive.

## Requirements and constraints

Use while loops.

## Example

3 5 -> lines 3, 4, 5.
