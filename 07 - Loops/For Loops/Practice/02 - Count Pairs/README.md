# 2 - Count Pairs

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** For Loops Practice  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Count pairs A, B whose sum equals S.

## Input

N, M, S.

## Output

The number of pairs with 1<=A<=N and 1<=B<=M and A+B=S.

## Requirements and constraints

Use for loops. Optional challenge: avoid the inner loop.
