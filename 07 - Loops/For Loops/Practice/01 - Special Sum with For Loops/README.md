# 1 - Special Sum with For Loops

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** For Loops Practice  
**Problem:** 1  
**Source status:** Verified assignment

## Description

Reimplement the Special Sum assignment using for loops.

## Input

T; each case has N followed by N values.

## Output

The sum of ai raised to i for each case.

## Requirements and constraints

Use for loops for the array values and their powers; a while loop may still control test cases.

## Example

2 3 4 -> 75.
