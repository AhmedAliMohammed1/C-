# 3 - Count Triples

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** For Loops Practice  
**Problem:** 3  
**Source status:** Verified assignment

## Description

Count triples satisfying the specified ranges and inequality.

## Input

N, M, W.

## Output

The number of triples with 1<=A<=N, A<=B<=M, 1<=C<=W, and A+B<=C.

## Requirements and constraints

Use for loops. Optional challenge: remove one nested loop.
