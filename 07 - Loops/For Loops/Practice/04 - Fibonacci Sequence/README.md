# 4 - Fibonacci Sequence

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** For Loops Practice  
**Problem:** 4  
**Source status:** Verified assignment

## Description

Print the first N values of the Fibonacci sequence.

## Input

N.

## Output

N values starting 0, 1, with each later value equal to the sum of the preceding two.

## Requirements and constraints

Use for loops.

## Example

N=6 -> 0 1 1 2 3 5.
