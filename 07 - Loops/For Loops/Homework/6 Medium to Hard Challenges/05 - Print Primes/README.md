# 5 - Print Primes

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** For Loops Homework - 6 Medium to Hard Challenges  
**Problem:** 5  
**Source status:** Verified assignment

## Description

Print all prime numbers strictly below N.

## Input

N.

## Output

Comma-separated prime values.

## Requirements and constraints

Do not leave an extra comma after the final value.

## Example

10 -> 2,3,5,7.
