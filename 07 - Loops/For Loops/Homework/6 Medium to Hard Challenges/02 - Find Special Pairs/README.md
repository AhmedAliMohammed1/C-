# 2 - Find Special Pairs

**Course:** Mastering 4 Critical SKILLS Using C++ 17  
**Section:** 07 - Loops  
**Set:** For Loops Homework - 6 Medium to Hard Challenges  
**Problem:** 2  
**Source status:** Verified assignment

## Description

Count fixed-range pairs whose sum is divisible by 7 and whose first value is smaller.

## Input

No input.

## Output

The count of pairs.

## Requirements and constraints

50<=X<=300, 70<=Y<=400, X<Y, and X+Y divisible by 7.

## Example

The assignment gives the count 8040.
